# Prompt cookbook

Proven prompts for extending this starter kit. Paste any of these into Claude Code (or Cursor, Aider, etc.) and watch it work. They lean on the conventions in `CLAUDE.md` and the skills in `.claude/skills/` so the agent does the right thing without re-deriving.

If you write your own and it works well, drop it in here. PRs welcome.
